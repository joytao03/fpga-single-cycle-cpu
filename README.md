# FPGA Single-Cycle CPU

This project implements a single-cycle CPU in SystemVerilog, including datapath and control logic components.

## Features
- Instruction decoder
- ALU
- Register file
- Memory interface
- Combinational control logic

## Overview
The processor is designed as a single-cycle architecture in which each instruction completes in one clock cycle. The project focuses on datapath design, control signal generation, and functional verification.

## Skills Demonstrated
- SystemVerilog
- Digital logic design
- Computer architecture
- FPGA verification and testing
